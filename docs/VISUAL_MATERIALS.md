# Visual Materials

This repository uses synthetic visual materials to group prototype concepts without publishing production code, private screenshots, uploaded media, or live operational data.

## Current Public-Safe Materials

| Prototype Area | Visual Treatment |
|---|---|
| POKE Weather | Public live source repo handles the real screenshot; this overview keeps a simple concept tile. |
| AVA OS | Dashboard system represented with abstract modules. |
| Archisys | Architecture critique represented with generic system blocks. |
| Visual Interfaces | Ideaspace, Vision Canva, and proactive AI concepts represented as abstract graph/canvas patterns. |

## Visual Boundary

Use synthetic diagrams, generated mock screens, and self-contained prototype screenshots only.

Do not add private uploads, faces without permission, customer data, account exports, private screenshots, raw data, credentials, deployment settings, or anything that lets unauthenticated visitors spend private model quota.

## API Spend Boundary

Public prototype links should either:

- avoid private API keys entirely
- call models only from a protected server route with quota controls
- run in fixed sample mode
- clearly disable generation for unauthenticated visitors

Browser-visible Gemini or Google API keys should be treated as exposed.
