# ThreatLens

Source repo: [ThreatLens---AI-Red-Teaming](https://github.com/brycejohnson1417/ThreatLens---AI-Red-Teaming)  
AI Studio link: [open prototype](https://ai.studio/apps/a4706f95-4f64-4d5b-818a-135f72121726)  
Status: unfeatured experiment

## What It Tests

ThreatLens tests whether AI-generated red-team simulations can be made visual and easier to inspect.

## What It Demonstrates

- Interest in failure modes.
- Security-themed UX.
- Simulation output design.
- Visualizing risk over a system graph.

## Key Boundary

This should be presented as a simulation prototype, not a real security scanner. It should not claim validated findings without real analysis and verification.

## What Would Make It Production-Ready

- Real scan inputs.
- Finding validation.
- Severity rubric.
- False-positive handling.
- Clear distinction between simulation and evidence.
