# Vision Canva

Source repo: [Vision-Canva](https://github.com/brycejohnson1417/Vision-Canva)  
AI Studio link: [open prototype](https://ai.studio/apps/b069e4d7-1e98-4472-9f17-4119e14e27f4)  
Status: active concept

## What It Tests

Vision Canva tests whether unstructured text can become an interactive entity-relationship graph on an infinite canvas.

## What It Demonstrates

- Entity extraction workflow.
- Graph/canvas UI.
- D3-style relationship layout.
- Turning AI output into inspectable structure.

## Key Boundary

Graph output should be treated as a draft structure until the user can inspect, edit, and confirm relationships.

## What Would Make It Production-Ready

- Manual graph editing.
- Confidence indicators.
- Large-input chunking.
- Export/import.
- Source references for generated relationships.
