# Archisys

Source repo: [Archisys-AI-System-Design-Sandbox](https://github.com/brycejohnson1417/Archisys-AI-System-Design-Sandbox)  
AI Studio link: [open prototype](https://ai.studio/apps/30324eb0-f0a1-4972-9bbf-f1e10dfe36a7)  
Status: active concept

## What It Tests

Archisys tests whether AI can give useful architecture critique on cloud/system diagrams.

## What It Demonstrates

- System-design thinking.
- Critique workflow design.
- Architecture review UX.
- Failure-mode analysis.

## Key Boundary

AI critique is only useful if the tool shows assumptions, uncertainty, and specific tradeoffs. It should not present generated criticism as guaranteed correctness.

## What Would Make It Production-Ready

- Structured diagram import/export.
- Explicit architecture assumptions.
- Repeatable scoring rubric.
- Source-grounded best-practice references.
- Versioned review history.
