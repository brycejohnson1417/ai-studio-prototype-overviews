# FaceSwap Studio

Source repo: [FaceSwap-Studio](https://github.com/brycejohnson1417/FaceSwap-Studio)  
AI Studio link: [open prototype](https://ai.studio/apps/c8552a40-e516-4b7c-bc87-036e199c0d2f)  
Status: active concept

## What It Tests

FaceSwap Studio tests whether identity reference matching, pose/style analysis, and generative image workflows can be shaped into a controlled creative tool instead of a generic image toy.

## What It Demonstrates

- Creative AI workflow design.
- Vision/reference input handling.
- Style prompt extraction.
- Generation review loops.
- Product thinking around sensitive creative tools.

## Key Boundary

This should be framed as a consent-first creative identity and style-transfer prototype. A public standalone deployment should not retain uploads by default, should explain acceptable use, and should not expose private model keys in browser code.

## What Would Make It Production-Ready

- Server-side model calls or explicit visitor-key mode.
- Consent and acceptable-use language.
- Clear upload retention policy.
- Abuse limits.
- Synthetic/self-owned screenshots only.
